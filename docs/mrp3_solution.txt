שאלה 3

אלגוריתם WW. F_j היא העלות המינימלית (הזמנה ואחזקה) מתקופה 0 ועד תקופה j כולל, ו-c_{ij} היא עלות הזמנה בתקופה i+1 עבור תקופות i+1 עד j:

F_j = min{F_i + c_{ij}}
c_{ij} = K + sum_{t=i+2}^{j} (t − i − 1)·V_t·h
בגלל אורך החיים, c_{ij} מוגדר רק כאשר j ≤ i + 3.
אם V_j = 0, לא מזמינים בתקופה j, ואז F_j = F_{j-1}.
