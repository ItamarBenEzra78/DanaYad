הגדרות המדדים:
C_j = זמן הסיום
F_j = C_j − r_j
W_j = F_j − t_j
L_j = C_j − d_j
T_j = max{0, L_j}
מבצעים את הג'ובים לפי הסדר שנקבע. אם ג'וב עוד לא הגיע, המכונה מחכה לו, כלומר זמן ההתחלה הוא המקסימום בין זמן הסיום של הג'וב הקודם לבין r_j.

שאלה 3 (רשות)
כל הג'ובים מגיעים בזמן 0.

סעיף 1
כל סידור שלא משאיר את המכונה ריקה ממזער את זמן הסיום המקסימלי. הג'וב האחרון מסתיים תמיד בסכום זמני הביצוע:
C_max = sum t_j = 8 + 3 + 1 + 4 + 5 = 21
לכן SPT, WSPT ו-FIFO נותנים כולם C_max = 21. כש-r_j = 0, הזמנים הריקים נעלמים, והסדר משפיע רק על המדדים של הג'ובים בתוך הרצף, לא על סוף הרצף.

סעיף 2
סידור SPT ממזער את סכום זמני הסיום. הג'וב שבמקום i נכנס לזמני הסיום של עצמו ושל כל הג'ובים שאחריו:
sum C_j = n·t_{[1]} + (n−1)·t_{[2]} + ... + 1·t_{[n]}
המקדם הגדול ביותר נמצא במקום הראשון. לכן כדאי לשים בו את הג'וב הקצר ביותר, וכך הלאה. עבור הנתונים:
5·1 + 4·3 + 3·4 + 2·5 + 1·8 = 47
הערה: עם זמני ההגעה מהטבלה, SPT לא היה הטוב ביותר (67 לעומת 60 ב-FIFO), כי הוא מחכה לג'ובים שעוד לא הגיעו.

שאלה 4
ניסוח כבעיית תכנות לינארי, כאשר r_j = 0 לכל j.
משתני ההחלטה:
x_{ij} = 1 אם ג'וב j מתוזמן במקום ה-i בסדר, ו-0 אחרת, עבור i, j = 1, ..., n.
פונקציית המטרה: ג'וב j במקום i תורם (n − i + 1)·t_j לסכום זמני הסיום:
min Z = sum_{i=1}^{n} sum_{j=1}^{n} (n − i + 1)·t_j·x_{ij}
אילוצים:
בכל מקום בסדר יש ג'וב אחד בדיוק:
sum_{j=1}^{n} x_{ij} = 1, לכל i = 1, ..., n
כל ג'וב מתוזמן במקום אחד בדיוק:
sum_{i=1}^{n} x_{ij} = 1, לכל j = 1, ..., n
אילוצי סימן:
x_{ij} = 0 או 1 (בינארי)
זו בעיית השמה. למטריצת האילוצים יש מבנה של הובלה, ולכן גם כשמרפים ל-0 ≤ x_{ij} ≤ 1 הפתרון האופטימלי יוצא שלם.

הצבת הנתונים, n = 5:
